# 平板虚拟宠物看板

归档日期：2026-06-08

## 概述

将 iPad LAN 看板页（`crates/vibe-core/assets/mobile/index.html`）重构为「虚拟宠物看板」——页面主体是一只活态宠物，通过表情/动作/气泡传达 AI 助手状态。

## 宠物角色

| 来源 | 宠物 | 名字 | 视觉特征 |
|------|------|------|----------|
| `cursor` | 小猫 | 咪咪 | 蓝紫项圈、圆耳、尾巴摇摆 |
| `claude_code` | 小狐狸 | 狐狐 | 暖橙毛色、大尾巴、戴眼镜 |
| `codex` | 小猫头鹰 | 咕咕 | 青绿羽毛、大圆眼、小翅膀 |

## 行为系统

| phase | 宠物行为 | 气泡语气示例 |
|-------|----------|--------------|
| `active` | 敲键盘/翻书/扇翅膀 + 弹跳 | 「键盘敲得噼里啪啦～」 |
| `waiting_user` | 举爪/问号 + 脉冲光环 | 「主人～喵需要你！」 |
| `stopped` | 庆祝跳跃 | 「喵！搞定啦～」 |
| resting（无会话） | 三只叠睡 + Zzz | 「大家都在打盹…呼…」 |

## 逻辑变更

- 新增 `pickActiveSource()`：仅返回 `active` / `waiting_user` 的来源
- 移除「全部来源」列表
- 无进行中会话时显示 `#restingView` 休息场景

## 文案表

### 宠物第一人称（speechBubble）

| phase | 咪咪 | 狐狐 | 咕咕 |

### 连接/footer

- 已连接 → `💚 连着呢 · HH:MM:SS`
- 连接中 → `🐾 正在找小伙伴…`
- 断开 → `💔 断开了 · 正在重连…`
